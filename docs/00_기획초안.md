## 1. 한 줄 소개
스터디카페 이용자가 시간대를 골라 좌석을 실시간으로 예약하고, 관리자는 예약·좌석·시간대별 혼잡도를 한 화면에서 관리하는 서비스.

## 2. 참고한 뼈대 (아이디어만, 코드 사용 없음)
OBM(방탈출 카페 예약, JSP/Servlet)의 뼈대 — 시간대 선택 예약(이미 찬 시간 비활성), 회원 포인트, 후기, 1:1 문의, 관리자 취소 처리 — 를 스터디카페 소재로 바꾸고 Spring Boot로 새로 설계.

## 3. 차별점 (내 것으로 만드는 부분)
1. 좌석 단위 예약 + 동시 예약 충돌 방지 (같은 좌석·겹치는 시간 이중 예약 0건을 시험으로 증명)
2. 포인트 원장(적립/사용/취소 이력) — 잔액은 원장 합계, 예약 취소 시 환급
3. 시간별·일별 혼잡도 통계 + 서버가 꺼져 있던 구간 누락 보충 (2차 white-eyes 경험 연결)
4. 체크인/퇴실, 미체크인 자동 노쇼 처리 (구현 정책: 첫 1시간 슬롯은 유지하고 이후 시간만 풀며 포인트는 환불하지 않음)

## 4. 사용자
- 비회원: 구역·좌석 현황 조회, 후기 열람
- 회원: 예약/취소, 체크인·퇴실, 포인트, 후기, 1:1 문의
- 관리자: 구역·좌석 관리, 예약 조회·강제취소, 문의 답변, 혼잡도 대시보드

## 5. 핵심 기능
| 영역 | 기능 |
|---|---|
| 계정 | 회원가입, 로그인(세션), 권한(MEMBER/ADMIN) |
| 좌석 | 구역(열람실/스터디룸) 목록, 좌석 배치 현황(시간대별 가능/불가) |
| 예약 | 날짜·시간(1시간 단위)·좌석 선택, 중복 방지, 취소(시작 N분 전까지), 내 예약 목록 |
| 이용 | QR/버튼 체크인, 퇴실, 미체크인 노쇼 자동 처리 |
| 포인트 | 이용 시 적립, 예약 시 사용, 원장 조회 |
| 후기 | 이용 후 후기·별점 작성, 목록 노출 |
| 문의 | 1:1 문의 등록, 관리자 답변 |
| 관리자 | 좌석 CRUD, 예약 관리, 시간별·일별 혼잡도 그래프 |
| 통계 | 시간별 점유율 집계(스케줄러), 일별 집계, 누락 구간 보충 |

## 6. 기술 스택 (안)
- Java 17, Spring Boot 3.x, Spring Data JPA, Spring Security(세션), Thymeleaf + Chart.js
- MySQL 8 (개발·시험은 H2 MySQL 모드 가능), Flyway 마이그레이션
- 테스트: JUnit5, 동시성 시험(ExecutorService)
- 배포: Docker Compose (WSL), CI는 GitHub Actions(빌드+테스트)

## 7. 개략 테이블 (Gemini 리뷰 반영)
member, zone, seat, reservation(seat_id, member_id, start_at, end_at, status, checked_in_at, checked_out_at), reservation_slot(seat_id, slot_start — UNIQUE, 한 시간당 한 행이라 겹침 예약이 DB에서 막힘), point_ledger, review, inquiry, cafe_policy(운영시간·휴무·최대 이용시간), occupancy_hourly, occupancy_daily

동시 예약 방지: 예약 한 건을 1시간 슬롯 행들로 쪼개 `(seat_id, slot_start)` 유니크 제약으로 이중 예약을 DB가 거부. 동시성 시험으로 0건 증명. (Codex 의견은 사용량 한도로 못 받음 — 11/11 이후 필요 시 재검토)
