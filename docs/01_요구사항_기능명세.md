# 요구사항 · 기능 명세

구현 상태는 2026-11-09 기준. "시험"은 자동 시험으로 확인, "화면 확인"은 실행 중인 앱에서 직접 확인한 것.

## 1. 정책 값
| 항목 | 값 |
|---|---|
| 운영 시간 | 지점마다 다름 (예: 강남점 9~23시, 홍대점 24시간 0~24시) — `branch.open_hour/close_hour` |
| 요금 | 구역마다 다름 (일반석 1,800~2,200 · 프리미엄/라운지 2,800~3,500 · 스터디룸 6,000~8,000 P/시간) — `zone.price_point_per_hr`. 1P = 1원 |
| 한 번에 최대 이용 | 8시간 (`cafe_policy`) |
| 적립 | 이용 1시간당 100P (퇴실 또는 자동 종료 시) |
| 취소 | 시작 60분 전까지 전액 환불 |
| 체크인 | 시작 10분 전 ~ 시작 후 10분 (넘으면 노쇼) |
| 연장 | 예약당 1회, 1~2시간, 바로 뒤 시간이 비어 있고 최대 이용·운영 시간을 넘지 않을 때 |
| 가입 환영 포인트 | 20,000P |
| 충전 | 10,000 / 30,000(+5%) / 50,000(+10%) / 100,000(+12%) — 데모 결제 |
| 예약 가능 기간 | 오늘부터 14일 뒤까지(화면 기준) |

## 4. 예약 상태
`BOOKED`(예약) → `CHECKED_IN`(이용 중) → `DONE`(이용 완료)
`BOOKED` → `CANCELED`(취소) / `NO_SHOW`(노쇼)
관리자 강제 취소는 `BOOKED`, `CHECKED_IN`에서 `CANCELED`로.
